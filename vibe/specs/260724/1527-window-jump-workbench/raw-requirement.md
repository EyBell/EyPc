## 第一性目标

Window Jump 的稳定管理与切换单位是一个真实主窗口。主窗口内部可以有动态变化的真实子窗口：默认切换主窗口时打开它当下的子会话；用户明确选择某个子窗口时，才精确打开该子窗口。

只展示用户可见、可操作且能证明身份与主子关系的窗口。系统句柄、控件、辅助层、透明/隐藏表面以及只有 CG 表面而没有可操作 AX 身份的记录不进入产品树。

## 当前用户事实

### 树与身份

- 普通应用显示“真实主窗口 → 已证明的真实子窗口”。同一应用的多个独立主窗口保持并列一级项，不创建应用级虚拟父节点。
- Finder/Explorer 是唯一虚拟结构，固定为“虚拟文件管理器父节点 → 真实主窗口”两级；文件管理器主窗口下面不展示第三级成员。
- `WindowTarget` 只持久化真实主窗口或文件管理器虚拟组。真实子窗口只存在于当前会话清单。
- 标题、应用名、位置、尺寸、列表顺序和“只有一个候选”只可帮助辨认，不能证明窗口身份、主子关系或换绑关系。

### 激活与失效

- 主窗口和固定槽位使用 `root-current`：请求只保存主窗口；调用时重新解析该根当前活动或最近活动的真实子窗口。子窗口、Tab、编辑页或对话变化不得改变收藏、列表置顶、别名或槽位。
- 用户选择真实子窗口时使用 `member-exact`：请求携带根与成员，操作前重验平台、应用、根、成员及关系，最终焦点必须命中该成员。
- 指定子窗口消失、变更父根或无法验证时必须明确失败，不得回退到主窗口、兄弟窗口或任意同应用窗口。
- 一个持久主窗口实例真正失效后，只能通过完整清单中的同应用候选让用户明确确认；即使只有一个候选也不能自动换绑。部分清单不能证明关闭或清除绑定。

### 子窗口能力

- 子窗口不持久化、不收藏、不列表置顶、不改名、不绑定槽位、不参与多选，也不提供页面置顶、强杀或批量动作。
- 子窗口只允许精确激活、能力允许时的精确关闭、只读详情及 Windows HWND 复制。
- 完整清单替换根/子家族；部分清单保留旧节点并标记缓存，不能证明某个子窗口已经关闭。

### 平台准入

- Windows 只从 `EnumWindows` 的可见、非 cloaked、可激活且有有效范围的顶层/owned popup 建立产品窗口；用同应用 `GA_ROOTOWNER` 证明真实根关系，过滤 `WS_CHILD` 控件、no-activate、透明、宿主、系统和 helper 表面，不调用 `EnumChildWindows`。
- macOS 以普通应用中的可操作 AX 窗口为准，只接纳允许的 `AXWindow`/`AXSheet`/`AXDialog` 角色；正 CGWindowID 只作身份佐证，`AXParent`/`AXTopLevelUIElement`/`AXWindow` 证明关系。CG-only、系统层、辅助层和无可操作 AX 身份的表面全部省略。
- 两个平台都必须在操作时重验实例、应用与关系，并验证最终焦点；不得绕过 Windows 前台保护，也不得修改权限、模拟输入或改写真实窗口标题。

### 交互与运行边界

- 普通主窗为 ARIA 一级 `treeitem`、真实子窗为二级；根 `Enter`/双击执行 `root-current`，子窗执行 `member-exact`。
- `ArrowRight` 展开或进入首个子项，`ArrowLeft` 返回父项或收起；搜索可临时展开命中子窗，但不覆盖手动展开状态。子窗消失、收起或被搜索隐藏时，焦点回到对应主窗口。
- 右键先聚焦再打开既有右侧动作层；`Ctrl+ArrowRight` 打开动作层，`Ctrl+ArrowLeft` 返回列表。`Escape` 先处理动作层，再处理搜索、编辑、换绑和选择。
- 功能默认关闭；窗口页只在用户显式刷新时扫描。十个固定 `mainHide` 槽位成功后不显示中转页，失败时打开窗口工作台并给出会话级诊断。
- 当前桥版本为 `wj21-main-child-window-tree`；Renderer、canonical preload 与 public preload 必须一致，旧桥在清单进入领域归一化前即阻断并提示重载。

## 已清退的关系规则

| 已清退路径 | 当前规则 |
| --- | --- |
| WJ-11–WJ-18 的环境快照、SkyLight/Space 查找、缓存、切换和桌面遍历 | 当前桥不包含这些路径；只使用可验证的根/成员身份与最终焦点 |
| WJ-17 的标题相似度、历史标题或唯一候选自动换绑 | 标题只供辨认；实例失效后必须人工确认并在原生成功后换绑 |
| WJ-18 的 CG/AX 标题等值门禁与 AX 序号回退 | 使用 PID/application、正 CG 身份佐证、精确 AX 映射和焦点回读 |
| WJ-20 的“普通应用成员全部吞并、不展示” | 普通应用展示真实根→真实子窗；只有稳定身份继续收敛到根 |
| 用应用、标题、位置、大小或候选数量猜主子关系 | 无正向原生证据则省略该表面，不创建应用级兜底组 |

## 验收事实

1. 浏览器/IDE 子会话变化后，原收藏或槽位仍通过主窗口打开该根当前子会话。
2. 明确选择子节点只打开该成员；成员失效明确失败且不回退。
3. 同应用两个独立主窗口保持两个一级节点。
4. Finder/Explorer 始终是虚拟父→真实主窗口两级，无第三级。
5. 企业微信等应用不再出现 CG-only、系统/helper 或控件句柄洪泛。
6. 完整/部分清单、搜索展开、折叠、右键、`Escape` 和焦点回根符合上述树合同。
7. 子窗口不存在收藏、置顶、槽位、多选、编辑、强杀或批量入口。
8. 旧 preload、关系不明或能力不可证时阻断，不猜测、不降级激活。
