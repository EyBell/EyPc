# Window Jump Workbench — Current User Facts

Tool: codex
Updated: 2026-08-04

## 第一性目标

Window Jump 的稳定单位是一个真实主窗口，而不是应用、标题、Tab 或当前 Space。一个浏览器主窗口内部从 Tab1 切到 Tab2 后，原收藏和槽位仍应激活同一个主窗口并保留它当下的 Tab2；同一浏览器的两个独立主窗口必须是两个目标。

快捷激活必须跨显示器和 macOS Space 工作。显示器 1 的目标位于桌面 4 时，即使显示器 1 已切到桌面 5、显示器 2 又独立切换了自己的桌面，槽位仍须只切换目标显示器并命中准确根 CGWindowID；非目标显示器的当前 Space 不得被改变。

## WJ-22 用户事实

### 唯一身份与存活

- macOS 唯一实例为 `darwin:PID:CGWindowID`，Windows 为 `win32:PID:HWND`，并同时校验平台、应用和原生 owner。
- 标题、Tab、位置、尺寸、顺序、当前显示器、当前 Space 和 `kCGWindowIsOnscreen` 不参与身份或死亡判定。
- 当前 AX/CG 清单缺席只能表示“暂不可观测”。只有针对保存实例的原生定点探测返回 `verified-gone`，才允许清除 `lastInstanceId/lastNativeRef`。
- 权限、API 或拓扑证据不足必须返回 `indeterminate` 并保留目标、别名、收藏、列表置顶和槽位。
- EyPc/uTools 进程重启后，会用持久逻辑目标和最后验证的原生身份定点恢复；浏览器进程或原生实例改变后必须人工确认。

### 根、子窗口与 Tab

- 普通应用显示“真实主窗口 → 已证明的真实原生子窗口”；Finder/Explorer 继续保持“虚拟父节点 → 真实主窗口”两级。
- 浏览器 Tab、IDE 编辑页等是主窗口内部状态，不是持久子目标。根和槽位使用 `root-current`，不得因为当前 Tab/标题改变而失效。
- 只有真实 AX/HWND 子窗口使用会话级 `member-exact`；成员失效时明确失败，不得回退到根或兄弟窗口。
- 同一应用、同一标题的独立根保持分离；标题或唯一候选不得自动换绑。

### Space 与会话缓存

- 十个槽位共享一份 preload 会话缓存，按唯一实例保存 `displayUuid + spaceId`，并按显示器独立保存当前 Space。
- 热缓存只刷新托管显示器当前 Space；冷缓存只解析当前目标；显式刷新可以预热，禁止后台轮询。
- macOS 定点解析依次使用 `SLSCopySpacesForWindows`、托管 Space 反向查询和隔离 JXA；缓存失效只驱逐当前目标并最多重试一次。
- 激活在原生桥内原子完成身份检查、存活检查、目标显示器 Space 切换、切换确认、精确根/成员激活和最终焦点回读。

### 目标与槽位隔离

- 树形汇总只负责显示，不得删除逻辑目标、合并收藏/别名/置顶或批量重映射槽位。
- 一个历史成员目标只有在唯一根关系得到证明且没有同根冲突时才可迁移到根；多个历史目标收敛到同一根时保留并进入人工恢复。
- 槽位候选确认只修改发起恢复的槽位：已有精确目标则复用，没有则创建全新的非收藏逻辑目标；不得复制旧混合目标元数据或影响其他槽位。
- 用户可以有意让多个槽位指向同一目标；重绑其中一个槽位不能改变另一个。

## 实施边界

- 本轮只重构窗口全链路，不改变 Codex、Files、MQTT、Ports、storage key、十个槽位 feature code/命令名/`mainHide` 或 uTools 生命周期 Hook。
- preload 窗口模块必须无顶层原生调用、进程或定时器；加载失败只降级 windows，其他 `window.eypcPlatform` API 保持。
- 会话缓存不持久化 Space、显示器或存活状态，不启动后台轮询。
- 保留无关脏树，禁止整文件格式化和顺手重构无关业务。

## 验收事实

1. 目标从当前 Space 清单消失时保留身份和槽位，定点探测仍可证明 live。
2. 目标显示器切走后，槽位切回准确 Space 和准确根；非目标显示器保持自己的当前 Space。
3. 两个同应用、同标题主窗口分别绑定和激活，不串线。
4. Tab1 绑定后切到 Tab2，仍激活同一根并保持 Tab2。
5. 最小化、隐藏、离屏或 `onscreen=false` 不显示“已关闭”。
6. 真正关闭只清理该实例的原生引用；逻辑目标和槽位进入显式恢复，其他槽位不受影响。
7. 热缓存不全量列举窗口；目标 Space 漂移时只定点刷新并重试一次。
8. Windows 的前台保护、关闭和置顶合同保持不变；非窗口业务与打包镜像零回归。
