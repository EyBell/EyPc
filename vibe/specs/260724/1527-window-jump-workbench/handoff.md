# Window Jump Workbench — Handoff

## Delivery State

`wj20-root-window-family / WJ-20.1 implemented; verification-pending` — the product switches one independently operable OS root-window family, not every internal native surface. Proven members collapse to the root; Finder/Explorer gains one virtual parent over independent root children; WJ-19 manual rebind still applies only after a concrete root disappears. WJ-20.1 centralizes the remaining page-facing tree/workbench rules without changing that behavior. Status: **实现与既有测试契约已更新；测试、`vue-tsc`、构建、uTools 重载和真实跳转均未执行**.

## Delivered Surface

- Domain/state: [windows.ts](../../../../src/domain/windows.ts#L1) owns raw member observations, the only title-blind root-family coalescer, shared target resolution and slot lookup; normalized `LiveWindow` is always a root. [windowTree.ts](../../../../src/domain/windowTree.ts#L1) now owns row IDs/projection, Finder/Explorer grouping, sort/search/flatten/focus, action targets/context, real-root-only selection, horizontal navigation, parent landing and positive-evidence migration merge. [state.ts](../../../../src/domain/state.ts#L1) migrates `scope`, group state and `alternateAliases` while still discarding title identity/history.
- Native bridge: Windows uses same-app `GA_ROOTOWNER`, activates the current/last member and validates final foreground root. macOS maps CG↔AX with `AXTopLevelUIElement`/`AXWindow` and `_AXUIElementGetWindow`, then validates the final focused root. Both fail closed on missing proof. Environment snapshots, private Space lookup/cache/switch, title and ordinal fallback are absent. See [preload/index.js](../../../../preload/index.js#L1), its byte mirror [public/preload.js](../../../../public/preload.js#L1), and [eypcPlatform.ts](../../../../src/platform/eypcPlatform.ts#L1).
- Runtime/UI: [appRuntime.ts](../../../../src/runtime/appRuntime.ts#L1) now supplies state to one `buildWindowTreeRows` call and retains native/persistence/message/focus side effects only. [WindowsPage.vue](../../../../src/pages/WindowsPage.vue#L1) consumes the domain `WindowRow`, uses one computed slot-target map, and renders one ARIA tree/contextual panel. Ordinary roots remain independent leaves; groups never join bulk close or expose unsafe group-wide native actions. [windowRebind.ts](../../../../src/domain/windowRebind.ts#L1) retains WJ-19 complete/partial/manual-confirm behavior for closed concrete roots.
- Verification: existing contracts were updated but not executed. Only read-only source searches, diff inspection and preload byte comparison were used; see [verify.md](verify.md#L1).

## User Validation Focus

Reload the non-hot-reloading preload and confirm `bridge=wj20-root-window-family`. For browser/IDE roots, switch tabs/editors and exercise internal dialogs: the main list must remain one root record, member focus/title must update only display/search, and the slot must jump to the current root content. Open two independent equal-title roots and require two targets. For Finder/Explorer, verify a stable parent with one/many children, parent landing priority, independent child operations, search auto-expansion, ArrowLeft/Right, contextual right-click and panel-first Escape; no-child parent must persist without launching the app. Then close one exact root and re-run WJ-19 sole-candidate manual confirmation, complete/partial refresh and focus-return gates.

## Safety Reminder

Neither the plugin nor this task should attempt to grant macOS accessibility/screen-recording access, alter an application title, or bypass Windows foreground protection. Force terminate runs only after an explicit user confirm.
