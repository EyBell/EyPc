# RAW-179 · EyPc V7 全局状态、交互、Tab 与 UI 体系

本记录只保存经用户确认的规范化当前要求，不保存原始提示词、对话、任务标题、回答内容、私有 Provider 标识或运行日志正文。目标是一次性完成全局 V7 重构，而不是为错误“待输入”增加局部特判；源码、测试与构建只证明产物就绪，真实 uTools Host 安装、身份和交互验收仍是独立门禁。

1. **状态与生命周期唯一真值。** 只有因果上仍未解决的 input、approval、Plan 选择或 Plan 实施 interaction 才能产生等待；回复、取消或 execution-start 必须在同一事务关闭对应实例并写入单调 tombstone。仅剩可执行 Plan artifact 时规范状态是 `stopped / 待继续`，历史已完成 Plan 不得重新合成 `waiting-input`；request 消失只关闭 interaction，不能推断 artifact 被取消。终态未读优先，证据冲突或不足进入 `unknown`，旧快照、重连和重放不得越过 tombstone，只有新 interaction instance 才能再次等待。
2. **生成合同与唯一 Kernel。** membership、activity、interaction、unread、plan-artifact、metadata、topology 七条 evidence lane 由 Provider adapter 输出原始证据，`CompanionKernelV7` 是唯一可变状态归约器；Provider、Controller、Main、Float 和各 Tab 不得再次推导 phase、bucket、cycle、计数或等待。Task/Presentation Snapshot、Command、FeatureTarget、NavigationIntent 与 ChildEnvelope 从单一 schema/manifest 生成 TS/CJS 类型和运行时校验器；同 revision 冲突隔离诊断，语义 no-op 不增加公开 revision。
3. **FeatureModule 与 RuntimeSlice Tab 体系。** Ports、MQTT、Favorites、Windows、Companion/Codex、Settings 以及 QuickFavorites/Action/Float 通过统一 FeatureModule 声明元数据、生命周期、后台策略、命令、菜单、帮助和诊断，并只消费 feature-scoped RuntimeSlice；页面不得接收完整 AppRuntimeSnapshot。可见性、连接期 ingestion、按需加载和 Companion 增量观察分别由模块策略拥有，禁止重复 watcher、过滤、计数与 capability 分支。
4. **统一命令、交互与跳转。** 按钮、快捷键、右键、More、抽屉、QuickJump、Main、Float 与 Action 必须通过同一 CommandCatalog、ActionMenuModel、LayerStack、KeybindingIndex、FeatureTargetRef 和 NavigationIntent；同一操作保持一致 target、参数、风险和结果回执。焦点、Escape、快捷菜单键、roving focus、焦点恢复和 surface execution owner 由公共层拥有；`accepted / dispatched / native-confirmed / read-confirmed` 不得互相冒充。
5. **有界增量性能合同。** Runtime 按 domain/revision 通知，非 Companion 变化不得生成 Float 全量快照；快捷键索引每个配置 revision 最多重建一次，MQTT 使用单一增量事务和 `followLatest`，诊断写入使用有界异步队列，Action 日志使用 cursor 增量，QuickJump 使用显式索引，高容量列表保持稳定 identity。热路径禁止同步文件写入、MQTT 全量删插、完整 AppState 无界 undo 和重复冷 preflight；同一语义事实不触发 IPC。
6. **项目级 UI 与无障碍体系。** 延续现有紧凑、键盘优先、macOS 原生视觉语言，以 primitives、semantic tokens、theme/density adapters 统一 Main、Float、Action 与全部 Tab 的颜色、字体、间距、圆角、控件尺寸、阴影、动效和层级。行级操作采用“上下文主操作 + 必要状态切换 + More”，淘汰含糊的单字按钮，使用现有 Lucide 图标、tooltip 和 accessible name；支持系统明暗主题、compact/default/comfortable、清晰焦点、文本缩放、reduced motion、forced colors、高对比度和自适应布局，状态不得只依赖颜色。
7. **一次性切换、验证与外部门禁。** V7 存储使用独立 namespace、copy-on-read、幂等且可回滚；内部可做只读 V6/V7 shadow comparison，但不得写回 V6 或发布混合 Kernel/Snapshot。清理旧 aggregate、投影、重复 watcher 和冲突测试后，只有状态、交互、Feature、性能、UI、契约、镜像、typecheck、全量测试、build、需求和错误记忆门禁全部通过，才可把完整 V7 标为 `artifact-ready`；发布、安装、真实 Host identity、Main/Float applied ACK、300ms interaction canary、30 秒无反弹及真实明暗/密度/键盘视觉验收需要另行明确授权。
