## 用户原话

> @image codex功能tab的悬浮卡片, 页面优化一下展示, 最好保留一行 标题做成悬浮提示, 额度展示按平台区分颜色

配图：展开浮窗顶部额度区被圈出，当前占四个视觉行 ——
`周限额 83% / 5 天后重置`、`Spark 周额度 100% / 5 天后重置`、`Claude` 分区标题、`5 小时限额 58% / 0 分钟后重置`、`周限额 89% / 0 分钟后重置`。

## 拆解

| # | 要求 | 含义 |
| --- | --- | --- |
| R1 | 保留一行 | Codex 段与 Claude 段合并为**一条水平行**；每个额度块自身也必须是单行盒。 |
| R2 | 标题做成悬浮提示 | 「周限额 / Spark 周额度 / 5 小时限额」等完整标题，以及重置时间，移到悬浮提示；行内只留短标 + 百分比。 |
| R3 | 按平台区分颜色 | Codex 与 Claude 的额度读数用不同颜色区分。 |

## 澄清（本轮已确认）

1. **一行内容量** — 选「短标 + 百分比」：可见 `周 83%` / `S周 100%` / `5h 58%`；完整标题与重置时间进悬浮提示。
   （备选「只留百分比」被否，因为不 hover 就分不清 5 小时窗口和周窗口。）
2. **平台色来源** — 选「外观工作台新增两个平台色」：在展开卡片主题里新增可配置的
   `Codex 额度色` / `Claude 额度色`，而不是写死品牌色，也不是借用 `--codex-running`。
   代价是 12 套内置主题预设与已保存主题都要给出默认值。
