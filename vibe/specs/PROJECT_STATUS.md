## Current Contracts

- Window Jump is disabled by default and never background-polls. The Tab loads live windows only on explicit refresh; Runtime keeps a session cache for silent slot jumps. Persistent `windowTargets.lastNativeRef` plus current/bounded verified titles form the durable logical-target profile; EyPc list pin is separate from favorite, actual Windows page topmost, and slot mapping. Slot features use `mainHide` but never schedule a second route hide; Runtime hides only after operation success. A stale reference gets one healthy real-time rescan/retry. Exact app identity is mandatory; one complete-scan high-confidence unique title candidate may replace the target only after native success, while partial/weak/tied/multiple candidates remain manual. Only a successful complete rescan with no exact/plausible candidate becomes accepted `target-closed`; every other opening fault is blocking and opens a visible fallback for global slots. On macOS, a CG window ID is not treated as `AXWindowNumber`: the bounded in-process/isolated Space bridge first reaches the selected Space, the same PID/CG record revalidates its own `kCGWindowName`, then `_AXUIElementGetWindow` must uniquely map one AX element to that CG ID and `AXFocusedWindow` must read back the same element. `AXTitle` never disproves the CG title on the exact path; title/ordinal is compatibility fallback only when exact mapping is unavailable. No title enters shell/JXA source and macOS makes no permanent-topmost claim. Windows “页面置顶” maps to `HWND_TOPMOST`. List-pinned rows lead, then all saved/live rows sort globally by application; Workbench List Taste applies (`Space` multi-select + advance, single/multi action panel, Esc clears selection before panel close); `Ctrl+Delete`/`Ctrl+Backspace` OS-close then confirm-force; `Ctrl+ArrowRight` opens the action panel; `↑↓` stays owned by the list via `windows.list.*` even while the action panel is open.
