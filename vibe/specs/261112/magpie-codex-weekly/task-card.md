### 聚合、来源与缓存

1. Magpie 本地、远端分别排除 free Codex 账号，再对本来源所有有效普通 `7days` 周窗口取算术均值。真实 0 参与；缺失、NaN、Infinity、unlimited 和 text 不按 0 计算。不得取第一账号或 last 账号代替汇总，不跨来源混合账号。当前决定的验收算例为 `0 + 85 → 42.5%`；`Token 344.98` 不抢占该周读数，算例不充当本轮接口实测。
2. 候选顺序为 `fresh 正周 > fresh 正 Token > stale 正周 > stale 正 Token > 明确零 > 缺失`；同层远端优先。周均值为零或无有效周数据时，余额仍只选一个账号，不求和，按 `promax → last → 原序` 兜底。
3. 任一参与均值的账号过期，汇总即过期；符合范围但缺有效周窗口的账号不进分母，标「部分数据」。失败保留最近成功快照并标过期；关闭 Magpie 立即隐藏；跨过重置时刻标「待刷新」，不得推算成 100%。
4. 球心格、允许补入的周环、实际展开卡、设置与外观预览共用同一周读数与完整 snapshot。周百分比计算保留小数，最终最多显示一位小数；`0 < p < 1` 显示 `<1%`。

### 展示与保留边界

1. 环固定表示普通周：Codex 原生周大于 0 时保持；Codex 为 0 或缺失时允许 Magpie 正周补入。Claude 的 0 是真实读数，不得替代；Claude-only 缺普通周时隐藏轨道，不跨平台补入。Claude 短周期与 scoped 窗口都不能补周环。
2. Magpie 球心 grid 优先；Magpie 周移入环后从球心去重，真实零值格收缩隐藏，但零值仍参与周均值及 key 特例阻断。Token、Grok、Cursor 不驱动环；液面、卡片形态和贴边线仍用原生额度，不因 Magpie 周均值改权。
3. 实际展开卡右侧完整显示来源、值和参与账号中最近的重置时间；左侧不再重复「M·周」或「M·Token」。原生额度块保持单行，Magpie 右侧为保完整值允许窄窗换行。右侧整组支持点击及 Enter／Space 立即刷新，沿用同一 `codex.quota.refresh` 命令。提示提供匿名账号明细、部分数据与过期／待刷新状态；父级 aria 也涵盖被移入环的读数及这些状态。
4. 唯一 finite 远端 key 特例保持：仅 Codex 来源开启、Codex 明确 free、无原生窗口且无任何 agent 读数时才允许使用；任何 agent 的明确 0 也阻断该特例。`codex-2` 金额不接入。设置／外观预览复用完整 snapshot，包括 Claude 权限，不伪造已授权或已连接状态。
