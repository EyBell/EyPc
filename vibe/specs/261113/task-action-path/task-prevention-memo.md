# 逐目标预防备忘录

状态：供人工或代理开工前消费；当前没有新增自动执行门禁，也不创建检测器或守护进程。本文只约束后续动作，不代替 G，不把方案变成已实施或已验证。

消费方式：先匹配 O，再逐项消费对应 P，回执逐项给出状态；Root 对照实际 diff 与真实证据后才接受。查不到条目、证据不足或状态未知时，不能把该项记为通过。

编号：G 是现有实施指导；O1–O7 是固定目标；P01–P21 是固定预防条目，每个目标 3 条。正文只引用这些 ID，不再写文档路径或正文互链。

共同限制：只保存必要状态、摘要、编号和锚点；原始聊天、命令、工具输出和凭据不落库。范围外只记建议。用户保留核心抉择，未单独授权不启动核心实现、提交、推送、构建、测试、安装或传包。

<a id="o1"></a>
## O1 任务范围与失效

对应：P01、P02、P03。依据 G 的可撤销范围；未证明开发责任时，不抢锁、不建成功基线。

<a id="p01"></a>
### P01 unknown 不等于通过或只读

- 触发：范围缺少可靠字段、无法证明新鲜，或准备把 unknown 解释成只读、通过或免除核验。
- 禁止：用仓库 dirty、缓存缺失、进入目录或没有发现本地 patch 推断授权；把已知开发责任降成无需核验。
- 最小动作：返回 unknown；已知开发交付记“待核验”，不宣布完成。
- 证据：任务引用、当前范围状态、未知原因和缺失项。
- 失败阻断：只阻断该次构建启动和成功声明；不改其他任务的既有改动。

<a id="p02"></a>
### P02 收窄先失效再停在途

- 触发：用户改为只读、只要方案、停止或缩小写集，包括等待构建期间收到该决定。
- 禁止：先等执行者退出，期间继续沿用旧开发授权；旧范围失效前启动新动作。
- 最小动作：先使旧范围失效并禁止新动作，再停止相关执行者，最后核清在途结果；请求停止不等于退出，接管前须对账晚到写入及其归属。
- 证据：失效时间、旧范围标识、停止请求、退出确认、晚到写入归属和结果是否已知。
- 失败阻断：阻断新构建与继续实施；在途结果未知则保持未完成，不回滚无关改动。

<a id="p03"></a>
### P03 写入来源不降低开发责任

- 触发：已知本任务要交付源码，但写入来自 shell、子 Agent 或外部编辑器。
- 禁止：把本地 patch 记录当成唯一证据；缺记录就改判只读。范围登记本身不得变成只读任务的必做写操作。
- 最小动作：由主控汇总同一开发责任；缺证据时保持待核验。
- 证据：交付责任、写入来源类别和尚未核到的项目。
- 失败阻断：只阻断该交付的完成声明；不改变其他已确认事实。

<a id="o2"></a>
## O2 锁等待与共享终态

对应：P04、P05、P06。依据 G 的互斥与共享终态；30 秒只是候选等待预算，实施前须与 660 秒总预算统一核算，不按轮询重置。

<a id="p04"></a>
### P04 等待绑定实际构建编号

- 触发：锁已被占用，准备等待或复用结果。
- 禁止：每次轮询重置单一有效等待预算；把元数据未写完、读取失败或旧锁缺元数据当成无锁；把另一次构建的结果冒充原结果。
- 最小动作：用编号、输入和环境绑定同次尝试。成功还须核对产物后才复用；失败则共享实际失败，不要求存在成功产物。
- 证据：构建编号、输入摘要、等待起止和对应终态。
- 失败阻断：阻断本次成功复用；不启动同输入的第二次自动构建，也不删除未知锁。

<a id="p05"></a>
### P05 失败共享且不自动重跑

- 触发：匹配尝试已失败，或另一会话等待同一输入。
- 禁止：只等锁消失后重跑；用构建失败文案描述正常占锁；超时后递归重试或连续 block。
- 最小动作：共享实际失败和构建编号；相同构建键不自动重跑，只有明确的重新核验才建新尝试。
- 证据：失败分类、构建编号、输入是否相同；不保存原始构建输出。
- 失败阻断：阻断同输入自动重试。pending 和 unknown 不消耗实际失败的自动续接次数，也不阻断单独授权的新核验。

<a id="p06"></a>
### P06 超时与未知分开

- 触发：单一有效等待预算耗尽，或持有者异常、PID 复用、元数据损坏、结果无法确认。
- 禁止：把 pending 或 unknown 写成失败或通过；按锁龄删锁；终止未知进程；为此扩大宿主总超时。
- 最小动作：超时记 pending，无法确认记 unknown；只由持有者释放自己的锁。
- 证据：预算、构建编号、状态和未确认原因。
- 失败阻断：只阻断本次结果接受；原持有者继续受其自身预算约束，不改其他构建的终态。

<a id="o3"></a>
## O3 实际发送包证据

对应：P07、P08、P09。证据只绑定实际发送副本；传输一致不等于安装、加载或代码安全已验。

<a id="p07"></a>
### P07 同一副本绑定摘要与身份

- 触发：准备报告上传、同摘要跳过、字节数或包身份。
- 禁止：解析、摘要和上传使用不同副本；用当前 dist 或 public 补填身份；执行包内代码。
- 最小动作：固定本次副本，计算摘要和字节数；能读时再读取身份字段。
- 证据：同一副本的摘要、字节数，以及可读身份或不可核验原因。
- 失败阻断：阻断“身份已核验”或“来源已证”的声明；不改变已有发送目标。

<a id="p08"></a>
### P08 身份缺失不新增一律拒发

- 触发：包身份缺失、冲突、损坏，或真实封装尚未确认。
- 禁止：新增“旧包全部禁止发送”；为补身份自动打新包；预设全部包都是同一封装。
- 最小动作：报告身份未验。仅要求指定摘要且摘要匹配时，不因身份不可读而额外拒发。
- 证据：不可核验分类、实际摘要，以及用户是否同时要求身份。
- 失败阻断：只阻断身份核验结论；不阻断已明确允许且摘要匹配的既有包发送。

<a id="p09"></a>
### P09 指定版本无法核验则暂停该次发送

- 触发：用户明确要求发送指定修复版本、摘要或身份。
- 禁止：不匹配仍发送；无法核验时自动构建替换候选；未指定版本时擅自要求与当前源码一致。
- 最小动作：先绑定期望摘要或身份；不匹配，或要求的身份无法核验时，暂停该次发送并说明。
- 证据：期望值、实际副本摘要或身份、暂停原因。
- 失败阻断：只阻断该次发送；不改选包、上传校验、目标变更检测和失败清理。

<a id="o4"></a>
## O4 文档与 SQLite 引用

对应：P10、P11、P12。仅本试点以关系声明 JSON 为唯一主本，SQLite 为可重建派生索引；不推广成全局强制存储模式。索引不证明正文事实已验。

<a id="p10"></a>
### P10 关系只由声明维护

- 触发：新增、修改或解释文档关系。
- 禁止：在本试点用正文互链冒充关系主本；把派生 SQLite 当第二主本；普通查询时顺手重建；把本试点模式推广成全局强制要求。
- 最小动作：只更新关系声明；正文各守职责。查询前先确认索引新鲜。候选状态摘要先按现行工具校验字段限额，再写入/重建；不足以容纳时保留必要净状态和ID引用，不扩schema或抬高限额。
- 证据：声明条目、来源锚点，以及查询结果或索引状态。
- 失败阻断：只阻断关系结论；不阻断直接阅读正文事实。

<a id="p11"></a>
### P11 索引异常不当结论

- 触发：查询返回 missing_index、stale_index、index_mismatch，或来源在建库后变化。
- 禁止：把异常解释成没有关联或查询成功；沿用旧索引猜测关系。
- 最小动作：保留错误状态；只对受影响索引做显式重建，再重新查询。
- 证据：错误码、声明版本和重建结果；派生库不提交。
- 失败阻断：只阻断该次关系查询结论；不回滚声明，也不改正文。

<a id="p12"></a>
### P12 原始内容不进索引

- 触发：准备写入范围状态、关系、回执或更新记录。
- 禁止：保存原始提示、聊天、命令、工具输出、凭据或完整源文。
- 最小动作：只保留决策所需的状态、摘要、ID 和来源锚点。
- 证据：字段清单能够证明没有原始内容。
- 失败阻断：只阻断该次写入；不删除无关记录。

<a id="o5"></a>
## O5 子 Agent 执行与主控核查

对应：P13、P14、P15。执行者只报告本单元结果；最终范围判断和接受归 Root。

<a id="p13"></a>
### P13 写集独占且不自行扩围

- 触发：派发执行者，或执行者准备回报。
- 禁止：一个写集多个写入者；执行者写最终接受；用自己的计划或绿色测试扩大业务范围。
- 最小动作：按派发给出的基线、目标、写集、排除项和停止条件执行。
- 证据：实际文件、相对基线 diff、逐项状态、已跑检查和未跑项。
- 失败阻断：只阻断该单元接受；不暂存、还原或提交他人的改动。

<a id="p14"></a>
### P14 未知结果不得报完成

- 触发：进程未退出、操作结果未知，或执行中范围失效。
- 禁止：在结果未知时只报完成；继续执行已失效范围内的动作。
- 最小动作：停止相关部分，回报已完成、未完成和未知项。
- 证据：在途状态、停止点、未知原因和保留的无关改动。
- 失败阻断：阻断完成声明及依赖它的后续单元；已确认的独立证据仍可保留。

<a id="p15"></a>
### P15 接受必须匹配证据级别

- 触发：准备接受实现、构建、发送或宿主结果。
- 禁止：用静态检查冒充运行通过，用构建冒充已发送或已加载，用手动模拟冒充真实 Stop。
- 最小动作：Root 按 G 对照范围、写集、diff、保留行为、定向证据和未验项。
- 证据：每项标明报告、静态已查、定向已验、真实入口已验或最终接受，并绑定当前输入或包。
- 失败阻断：只阻断相应接受级别；较低级别的已有证据不撤回。

<a id="o6"></a>
## O6 规则优化抽取与全局候选

对应：P16、P17、P18。候选只是记录，不因本文存在而变成现行规则或全局规则。

<a id="p16"></a>
### P16 每条候选状态独立

- 触发：记录规则优化、错漏排查或全局候选。
- 禁止：一条被接受就连带启用其他条目；把建议、草稿或未决项写成已生效。
- 最小动作：每条单独记现象、对应 O/P、证据、状态和最小建议；F1/F2 等短选项须回到原轮及其选项含义，不跨对话或回合继承同名授权。
- 证据：候选 ID、当前状态、依据和未验项。
- 失败阻断：只阻断该条进入规则或实现；不改变其他条目的状态。

<a id="p17"></a>
### P17 范围外只记建议

- 触发：发现远端锁、打包器、全局规则、其他项目或产品功能问题。
- 禁止：把范围外改动混入当前写集；自动修改全局规则或记忆。
- 最小动作：记录现象、影响、最小建议和待验证项，必要性变化先上报。
- 证据：建议所依据的现象和它尚未覆盖的范围。
- 失败阻断：阻断范围外改动；不阻断当前已授权的文档工作。

<a id="p18"></a>
### P18 用户保留核心抉择

- 触发：技术不确定性需要收敛，或候选会改变用户可见行为、权限或核心实现路线。
- 禁止：把可调查的技术问题擅自升成新业务限制；代替用户选择核心方案；放宽只读与权限边界。
- 最小动作：继续收敛证据，把已决项与用户保留项分开。
- 证据：已决定、待用户抉择和不影响当前文档的项目。
- 失败阻断：阻断把未决项写入生效规则或启动核心实现。

<a id="o7"></a>
## O7 专门对话的持续检测与统筹

对应：P19、P20、P21。新对话只承接已点名的检测或统筹，不自动获得实施权。

<a id="p19"></a>
### P19 新聊天不自动启用

- 触发：另起专用检测或统筹对话。
- 禁止：因创建聊天而自动启用 Hook、全局规则或周期任务；把聊天存在当成核心实现授权。
- 最小动作：只承接该对话中已点名的检测、对照和统筹范围。
- 证据：点名范围，以及本次新对话未新增或启用 Hook、全局规则、周期任务的证据；不据此推断既有机制全部关闭。
- 失败阻断：阻断自动启用和越权实施；不阻断人工阅读本清单。

<a id="p20"></a>
### P20 清单不升级成守护

- 触发：准备把本清单实现成检测器、守护进程、轮询或调度器。
- 禁止：新增自动执行门禁；用持续扫描代替一次具体核查。
- 最小动作：开工时匹配 O、消费对应 P，并逐项回执。
- 证据：回执中的条目状态，以及 Root 对照 diff 和真实证据的结果。
- 失败阻断：阻断新增自动执行机制；不阻断一次人工或代理核查。

<a id="p21"></a>
### P21 统筹不启动核心实现

- 触发：专门对话发现后续核心工作或要求继续推进。
- 禁止：未另获授权就改 Hook、提交、推送、构建、测试、安装或传包。
- 最小动作：把建议交回原任务，保持独立状态；核心实现等待单独授权。
- 证据：建议、对应 O/P、授权缺口和未执行的核心动作。
- 失败阻断：只阻断核心实现启动；不阻断继续记录和对照。
