# Codex 外观编辑：已确认需求

spec_id: SPEC-261030-CODEX-APPEARANCE-EDITOR

## RAW-001

state: active
authority: user-stated

外观页的预览内放水球、卡片和散开控件；右侧依次显示部件、主题和操作。未选部件时显示「选择」，选中后在框内显示部件名，参数区不重复名称；模型与选择框双向联动。主题框显示当前名称及修改状态。操作可悬停或点击展开，支持保存、另存和仅重命名已保存主题，保留历史备选数据。部件修改即时生效；切换主题前处理未保存的修改，Esc 依层次处理名称、菜单和编辑，可保存、恢复或继续；恢复不得覆盖其他入口的新值。更多选择同一行右侧显示水球、卡片和贴边线，窄窗口保持可操作。仅实施 EyPc；正式设计偏好查询未通过时，按用户后续决定继续，仍保留该未通过状态。

## RAW-002

state: active
authority: user-stated

外观编辑区收紧间距并精简重复套框，预览和参数作为同级区域；保持预览区高度、模型大小和全局导航、状态栏。部件、主题和操作直接排列，优先保证常用名称完整显示；窄窗口按顺序换行。模型部件名称平时隐藏，鼠标悬浮或键盘聚焦时显示对应名称；移开或失焦后隐藏，已选标记与参数继续保留。
