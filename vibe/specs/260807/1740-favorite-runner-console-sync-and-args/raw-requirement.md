# RAW：收藏运行控制台、逐项同步与动态参数

Tool: claude
Date: 2026-08-07

来源：对 [260806/1120 收藏快开增量](../../260806/1120-favorite-quick-open-runners-slots/spec.md#L1) 的整体评价对话。用户对评价逐条给出决定，本文件是这些决定的规范化记录。

## 用户决定原文要点

1. 搜索排序和执行记忆排序**没有问题**，不改。
2. 矩阵槽位每个系统默认 10 个没有问题，按当前系统自动适配、每个系统只加载 10 个。**但要能全局同步**，并且**每一个收藏项可以选择是否同步**。
3. 重命名**不应该掉信任**，按建议优化。
4. ~~终端模式**封装一个展示端**，把实际执行的结果和命令行放进这个页面进行交互。~~ **同日修订：不需要封装展示终端。** 改为「自适应地去相关的记录」——如果存在相关日志，插件自动找到并交给系统打开。
5. **输出和退出码**统一体现（不再依附于被否决的展示页，改为落在运行记录上）。
6. 参数**可以考虑动态**。

## 规范化需求摘要

- 收藏搜索排序与使用学习维持 260806/1120 已交付合同，本增量不改动、不再复议。
- 槽位仍为「每系统 10 个、按当前系统自动加载」；新增逐项同步选择：每个收藏可标记参与同步或仅本机保留。
- 运行器「已信任」状态不随收藏同步到其它机器；同步只搬配置，信任在每台机器上各自确认。
- 信任指纹不再无条件包含收藏名称；仅当参数或工作目录实际引用 `{name}` 时纳入。既有已信任配置一次性平滑升级，不得让存量用户集体掉信任。
- 不新增插件内终端或控制台 UI。后台运行改为留下一条本机运行记录（命令行、工作目录、耗时、状态、退出码），并把相关日志找出来交给系统默认程序打开：自采集 run log 与运行器声明的日志路径为确定来源，运行窗口内被修改的文件为推测候选。后台模式不再是发射即忘。
- 运行器参数支持声明式动态位，执行前收集用户输入；输入整体作为单个 argv 元素，不分词、不解析 shell、不二次展开占位符。

## 安全与范围

- 日志定位分确定与推测两档，UI 不得混同。系统级日志检索与需要提权的进程写入追踪明确不做。需要真 TTY 的场景保留现有「系统终端」模式作为逃生舱，其退出码不可得。
- 动态参数不得成为注入面：用户输入不参与占位符展开，不做分词，长度与数量沿用既有上界。信任指纹覆盖参数**声明**而非每次填写的值。
- 同步只使用 uTools 既有账号级数据库能力，不新增自建云端、不上传凭据、不上传运行输出与命令行历史。
- 不实现固定角独立窗口（仍属第二阶段），不监测或移动 uTools 主搜索窗。

## 验收意图

- 老数据升级后：收藏默认保持可同步，运行器信任不丢失，本机档数据不出现在其它机器。
- 标记为仅本机的收藏，在开启 uTools 同步的另一台机器上不出现，且不影响其它收藏的同步。
- 后台与控制台模式都能给出退出码；非 0 退出必须可见，不再静默成功。
- 动态参数的输入值出现在命令行预览与控制台回显中时，与实际传给进程的 argv 元素逐字一致。
- 自动化需覆盖领域、Runtime、Preload、路由、UI、类型与生产/uTools 构建；三平台真实宿主与多机同步结果单独标记。
