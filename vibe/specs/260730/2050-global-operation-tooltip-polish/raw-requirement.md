# Raw Requirement: 全页面按钮悬浮提醒优化

Tool: codex
Date: 2026-07-30
Status: `captured`

## User Request

> 核验所有的这个按钮悬浮的这种提醒效果优化所有的这个页面。

## Working Interpretation

- 核验 EyPc 主应用全部页面和共享组件中的按钮/操作控件，确保鼠标悬浮与键盘聚焦时都能获得统一、可读的操作提醒。
- 复用全局 `OperationTooltipLayer`，统一标签、快捷键、补充说明和禁用原因的展示，不按页面重复实现提示气泡。
- 消除主应用 Codex 页面自有伪元素提示与全局提示层同时出现的重复效果。
- 独立 Float 子窗口不挂载主应用提示层，继续保留其自身提示实现。
- 不改变按钮业务行为、快捷键绑定、页面布局或数据流。

## Acceptance Boundary

- 主应用所有按钮均存在可推导的操作名称，悬浮或聚焦时只显示一个统一提示。
- 原生 `title` 中的快捷键可拆分为操作名称与快捷键徽标，普通括号文本不得误判为快捷键。
- 页面已有 `data-tip` 补充说明可由统一提示层承接。
- 控件状态或提示属性动态变化时，当前可见提示同步刷新。
- 提示出现/消失不阻塞点击，按下、失焦或窗口失活后不残留；减少动态效果偏好得到尊重。
- 验证遵循项目用户自有验收策略：仅执行静态审计，测试、typecheck、build 和运行态 UI 由用户验收。
