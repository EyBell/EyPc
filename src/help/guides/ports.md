# 端口进程

扫描本机 TCP 监听进程，按端口/进程整理，并可安全终止占用端口的进程。

**默认状态：** 启用。可通过设置 → 维护 → 功能开关关闭。

## 入口

- 主窗口顶栏 **端口进程** Tab（启用后出现）
- uTools 关键词：`端口进程`、`端口清理`、`kill port`、`ports`

## 主界面

- **结果列表：** 当前扫描到的监听项（按 `进程:端口:协议` 去重）
- **分组栏：** 自建分组与分组夹，用于筛选与整理；可用 `Ctrl+Shift+W` 展开/收起
- **搜索：** 过滤列表；在搜索框内仍可配合部分列表快捷键
- **详情抽屉（左）：** 查看选中项详情
- **动作抽屉（右）：** 终止、强杀等操作；与按钮、右键菜单走同一套命令

窄屏时侧栏会收进当前 Tab 内，不再横向撑破页面。

## 常用操作

1. 打开端口页后执行刷新/扫描，得到监听列表。
2. 用搜索或分组筛选目标端口/进程。
3. `↑` / `↓` 移动焦点；`Space` 等多选相关操作按动作抽屉提示使用。
4. 打开右侧动作抽屉，选择 **终止** 或 **强杀**。
5. 普通终止会要求确认；强杀前会再次核对当前 PID 与端口归属，避免误杀已换绑的进程。

### 分组与分组夹

- `Ctrl+T`：新建分组夹并聚焦分组栏
- `F2`：编辑分组（名称/规则/颜色等完整编辑）
- `Shift+F2`：仅重命名
- `Ctrl+F2`：在分组栏焦点下，变更当前组所属分组夹
- `Ctrl+S` / `Ctrl+Enter`：保存编辑；`Escape`：取消
- 编辑层内 `Tab` / `Shift+Tab` 只在字段间循环，不会切到别的主区域

## 关键快捷键

以下为默认值，可在 **设置 → 快捷键**（作用域「端口」）改绑。

| 操作 | 默认 |
| --- | --- |
| 刷新扫描 | `Ctrl+R` |
| 切换左右栏 | `Tab` / `Shift+Tab` |
| 详情 / 动作 | `Ctrl+←` / `Ctrl+→` |
| 终止 | `Delete` / `Backspace` |
| 强杀 | `Ctrl+Delete` / `Ctrl+Backspace` |
| 应用分组筛选 | `Ctrl+Enter`（分组相关上下文） |
| 展开/收起分组栏 | `Ctrl+Shift+W` |
| 隐藏插件窗口 | `Shift+Escape` |

页顶 `?` 可查看当前页命令提示；按住 `Ctrl`（macOS 为 `⌘`）可预览部分控件上的快捷键。

## 风险与边界

- **终止** 会结束真实进程，请确认目标无误。
- **强杀** 风险更高，仅在普通终止无效且你确认目标正确时使用；运行时仍会校验 PID/端口匹配。
- 分组/文件夹元数据只存在插件内，不会改动系统防火墙或网络配置。
- 通用键盘（快速跳转 `F`、左右抽屉约定）见 **设置** 功能说明。

## 与其它功能的关系

端口页与收藏、MQTT 等共用同一套左右抽屉与焦点恢复习惯；快捷键冲突与改绑在 **设置** 中统一管理。
