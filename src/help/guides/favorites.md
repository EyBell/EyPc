# 文件收藏

把常用文件与文件夹路径收成插件内元数据，支持分组整理、默认打开、受信任脚本运行、在资源管理器中定位和复制路径。另提供跨分组只读「快开」与 10 个全局文件槽。

**默认状态：** 关闭。需在设置 → 维护 → 功能开关中启用后，主 Tab 与相关 uTools 入口才会按启用状态出现。

## 入口

- 主窗口 **文件收藏** Tab（管理台）
- uTools：`文件收藏` / `favorites`（管理）；`文件快开` / `quick favorites`（快速打开）
- uTools 全局文件槽：`EyPc 文件槽 1` 至 `EyPc 文件槽 10`；在 uTools 快捷键设置中为需要的槽位绑定全局快捷键

## 两种模式

### 管理台（完整收藏页）

- 左侧容器（分组）与右侧条目；窄屏下容器可收成侧层
- 可新增、编辑、移动、复制焦点、浏览一层目录列表
- 支持标签、颜色、当前系统自定义运行器等元数据
- 详情抽屉与动作抽屉：打开或运行、定位、复制路径、分配文件槽、重置单项学习、移除收藏等
- 顶部「文件槽」打开紧凑 1–10 槽管理器，可分配/替换、清除、测试，并跳转 uTools 快捷键设置
- 顶部「重置学习」清除全部使用偏好；单项重置位于该收藏的动作抽屉

### 快开（Quick）

- 进入后自动聚焦一个跨全部分组的搜索框，并高亮第一条；结果显示类型、路径与分组面包屑
- 空查询优先显示近期/常用收藏；搜索时先看文本精确、前缀和包含匹配，再参考该查询与全局的成功使用记录
- 前 10 项显示 `1…9、0`；抽屉关闭时按 `Ctrl+1…Ctrl+9` / `Ctrl+0` 立即执行对应结果
- 仅搜索 / 打开或运行 / 定位 / 复制路径
- **不继承**管理台的多选或抽屉目标；每次进入是干净的只读操作状态
- 不会出现管理类编辑、批量元数据改动

## 常用操作（管理台）

1. 启用功能后打开收藏 Tab。
2. `Ctrl+N` 新增目标；或 `Ctrl+O` / `Ctrl+Shift+O` 点选文件 / 文件夹后进入审核确认再保存。
3. `Tab` / `Shift+Tab` 在分组区与目标区之间切换。
4. `Enter` 打开或运行；`Ctrl+Enter` 定位；`Ctrl+C` 复制路径。
5. `F2` 打开完整元数据编辑；`Shift+F2` 行内重命名。
6. `Ctrl+S` / `Ctrl+Enter` 保存编辑；`Escape` 按层取消/关闭。
7. 移除收藏只删除插件记录；确认后可用一步撤销（元数据级），**不会删除磁盘上的真实文件或文件夹**。

目录浏览为非递归只读，不跟随符号链接；不会在磁盘上创建、移动、重命名或删除文件。

## 自定义运行器

文件和文件夹默认仍由系统打开。需要直接运行脚本时，在收藏编辑器中切换到「自定义运行器」：

1. 选择后台启动或系统终端。
2. 填写可执行程序：使用绝对路径，或填写系统 `PATH` 中的程序名。
3. 每行填写一个参数，可使用 `{path}`（收藏路径）、`{dir}`（目标目录）、`{name}`（收藏名称）；需要每次现填的值写成 `{ask:名称}`（必填）或 `{ask:名称=默认值}`（可留空取默认）。
4. 使用目标目录，或填写当前系统的绝对工作目录。
5. 检查解析预览并确认信任。常见脚本可一键填入建议，但建议不会自动取得信任。

「脚本自身日志」是选填项：如果你的脚本自己会写日志，把它的绝对路径填进去（可用 `{path}`、`{dir}`、`{name}`），跑完就能一键打开。插件只读取和打开这个文件，不会创建它、更不会执行它；填相对路径会被忽略。

信任按 macOS、Windows、Linux 分别保存，且**只能在对应系统上配置**：编辑器读写的始终是你当前所用系统那一份，不能在 macOS 上预先给 Windows 配好，也不会覆盖或清掉其它系统已保存的配置。平台、收藏路径或运行器配置变化后必须重新确认；未信任或畸形配置不会执行。**改名不会掉信任** —— 除非你的参数或自定义工作目录里用了 `{name}`，那种情况下名称本身会进入实际命令，改名仍需重新确认。后台模式只确认进程已启动，不保存输出或跟踪退出码；终端模式找不到受支持终端时会明确失败，不会改为后台运行。Windows `.cmd` / `.bat` 请使用脚本建议生成显式 `cmd.exe` 参数，不能把脚本本身填成可执行程序；PowerShell 遵循机器现有执行策略。

## 运行时现填参数

参数里写了 `{ask:...}` 的运行器，每次运行前会弹出一个小窗口让你填值，并实时显示将要执行的完整命令行；`Ctrl+Enter` 运行、`Escape` 取消，取消就什么都不会跑。同一个名称在多个参数里出现只问一次。上次填的值会在本次使用期间记住，不会写进收藏、也不会同步。

- 你填的内容**整体作为一个参数**传给程序：不会按空格拆分，不会被当成命令解析，里面写 `{path}` 之类也只是普通文字。
- `{ask:...}` 只能写在参数里。可执行程序和工作目录必须是固定的，避免一次输入改变「跑的是什么、在哪跑」。
- 改动 `{ask:...}` 的声明属于改配置，需要重新确认信任；只是换填的值不需要。
- 文件槽或快开数字键触发这类运行器时，会先把窗口显示出来让你填，而不是悄悄失败。

## 运行结果与日志

后台模式运行的脚本，输出会被自动记录到插件目录下的一份运行日志里，收藏行上会显示这次运行的结果：

- `运行中` / `已成功退出（退出码 0）` / `以非 0 退出码 N 结束` / `已被信号 X 终止`。**「已启动」不等于「成功」** —— 启动只代表系统接受了这次调用，真正的成败看退出码。
- 在收藏的动作抽屉里可以「打开运行日志」，填了脚本自身日志且文件确实存在时还会多一项「打开脚本自身日志」。日志一律交给系统默认程序打开，插件内没有终端。
- 运行日志只保留最近若干份，单份超过约 2MB 时保留末尾部分并标注已截断。日志和运行记录都只留在本机。
- 退出码只在插件运行期间可观测：插件退出后脚本仍会继续跑完（这是有意的），但重新打开插件不会补回那次的退出码。
- 系统终端模式下进程归终端应用所有，退出码拿不到，界面会直接这么说，不会编一个。

## 10 个文件槽

1. 在完整收藏页选中已保存的文件或文件夹，从右侧动作选择「分配到文件槽…」，或点击顶部「文件槽」。
2. 在 1–10 槽中分配/替换当前目标，按需测试，并跳转 uTools 设置绑定全局快捷键。
3. 槽位按操作系统分别保存，同一数字可在三套系统绑定不同收藏；分配和清除只作用于当前所用的系统。
4. 同一个收藏在同一系统上最多占一个槽：把它分配到新槽时，它在该系统的旧槽会自动腾空（其它系统的绑定不受影响）。

文件槽的“静默”只表示不弹出 uTools 主窗口；终端运行器仍会打开系统终端。槽位未分配、路径失效、运行器未信任或启动失败时，插件会打开槽管理器并显示修复原因。实际目录浏览中的未收藏行需先收藏才能绑定。

## 搜索学习

- 只有系统或运行器**受理了**这次打开/启动才会增加偏好；定位、复制以及被拒绝或失败的启动都不计入。部分系统只回执“已接受请求”而不回执最终结果，这类也按受理计数。
- 使用记录随时间衰减，主要帮助常用目标在同一文本匹配层级中更靠前，不会越过更精确的文本结果。
- 学习记录有数量上限；可在完整收藏页重置单项或全部记录。快速页不会修改配置。

## 路径与健康状态

- 路径缺失、离线或权限不足时，收藏记录仍保留，界面会提示健康/失败状态，而不是静默删掉条目。
- Windows 盘符与 UNC 路径比较时忽略大小写并规范化分隔符；POSIX 路径保持大小写敏感。
- 打开 / 定位 / 复制的结果会区分：已确认成功、已交给宿主、定位回退为打开、失败等，避免误以为一定落盘成功。

## 关键快捷键

| 操作 | 管理台默认 | 快开 |
| --- | --- | --- |
| 打开 | `Enter` | `Enter` |
| 定位 | `Ctrl+Enter` | `Ctrl+Enter` |
| 复制路径 | `Ctrl+C` | `Ctrl+C` |
| 详情 / 动作 | `Ctrl+←` / `Ctrl+→` | 同左（动作为安全只读集） |
| 执行第 1–10 项 | — | `Ctrl+1…Ctrl+9` / `Ctrl+0`（抽屉关闭） |
| 新增 | `Ctrl+N` | — |
| 选文件 / 选文件夹 | `Ctrl+O` / `Ctrl+Shift+O` | — |
| 切栏 | `Tab` / `Shift+Tab` | — |
| 保存编辑 | `Ctrl+S` / `Ctrl+Enter` | — |

## 风险与边界

- **移除收藏 ≠ 删除文件。** 磁盘内容不受影响。
- 快开不会执行管理台才有的破坏性元数据操作。
- 点选审核层未确认前不会写入收藏。
- 不支持原始 shell 命令、运行器环境变量或凭据保存；参数始终按独立字符串传递。
- 本期没有固定角面板，也不会监测或移动 uTools 主搜索窗。

## 与其它功能的关系

左右抽屉与快速跳转习惯见 **设置** 说明。收藏与端口、MQTT 的快捷键分属不同作用域。
