# 设置

管理功能启用与 Tab 顺序、分层快捷键配置、共享工具偏好，以及存储与解析诊断。本篇同时说明插件级**通用键盘习惯**（各功能页会交叉引用此处）。

**默认状态：** 始终启用（不可关闭）。

## 入口

- 主窗口 **设置** Tab
- 默认快捷键：`Ctrl+Alt+S`
- uTools：`eypc-settings`

## 两个顶栏分区

### 快捷键

- 按作用域筛选：全部 / 全局 / 端口 / MQTT / 收藏 / 窗口跳转 / Codex / 设置
- 搜索命令（默认 `Ctrl+F`）、按冲突/用户改动/禁用过滤
- 行内可录制快捷键、编辑 When 表达式、恢复默认、禁用
- 修改先落在设置页草稿，**保存**后才写入运行时快捷键配置；可放弃草稿
- 非编辑中的命令行支持左侧详情、右侧操作与右键菜单（与其它页同一套抽屉习惯）
- 冲突提示基于「同一时刻可能同时成立」的 Tab / 层 / When，而不是全局键位绝对唯一

### 维护

侧栏分区：

| 分区 | 作用 |
| --- | --- |
| **功能开关** | 启用/关闭顶层功能，拖拽或箭头调整顺序；顺序同时影响主 Tab 与 `Ctrl+Shift+数字` |
| **工具系统** | 共享悬浮预览开关与延迟；键盘预览不受「鼠标悬浮预览」开关影响 |
| **层级优先级** | 只读查看快捷键接管层优先级 |
| **存储状态** | 查看 SQLite / 插件存储 / localStorage 等模式与 MQTT 归档相关状态 |
| **Layer Commands** | Esc、关闭层、搜索层等维护命令的绑定 |
| **解析候选** | 输入快捷键与上下文，预览谁会命中 |
| **保留键与接管层** | 宿主/系统保留键规则一览 |
| **安装诊断日志** | 开关独立运行日志，选择 `error / info / debug`，查看会话、文件和容量，并打开当前文件/目录或确认清理 |
| **窗口诊断** | 查看本次窗口激活记录；开发环境可附加有界操作追踪 |

功能开关中：设置本身锁定为开启；关闭某功能后其 Tab 隐藏，若从外部仍路由到该功能，会落到维护「功能开关」以便重新打开。

本页每行功能旁的 **说明** 按钮即打开各功能操作说明（Markdown）。新增顶层功能类型，或改动某功能的用户可见行为时，必须同步新增或更新对应说明文档。

### 安装诊断日志

- `eypc-runtime-diagnostics-v3` 当前安装验证默认**开启**并使用 `debug`；设置带 `userConfigured`，任何显式选择和开关都会永久保留。问题闭环后的正式版本只允许把从未手动配置者迁移为默认 `error`。
- `error`：只写失败和不确定结果。
- `info`：再写用户操作开始/结果、真实状态变化、真实任务包发布、缓存冷热、快捷键/手动跳转和归档重要阶段。
- `debug`：再写每次规范化观测、全部 lane 水位、before/after、接纳/拒绝、same-state no-op、目标选择、focus no-op、队列合并和定向核验。
- 日志是纯文本 JSONL，固定写入 uTools 用户数据目录下的 `eypc-diagnostics`。页面会显示本机精确目录和当前文件；可直接点 **打开当前文件**（尚未生成时禁用）或 **打开日志目录**。
- 点 **清空日志** 后会先显示确认。确认后只删除日志模块自有的 `runtime-*.jsonl`，不会删除日志目录、目录里的其它文件，也不会改变开关或等级；若日志仍开启，后续事件会创建新的当前文件。
- 每条记录有时间、顺序号、会话/进程身份，以及适用的 operationId/traceId、精确 taskRef、Provider 状态、修订、水位、缓存来源、路径、动作阶段、错误码和耗时。Codex 归档的 intent、confirmation、preflight、write、两次 server verify、Desktop sync、native ACK、Kernel commit、UI removal/reconciliation 均可关联。单文件最多 8 MB、总量最多 64 MB、保留 14 天。
- 日志不会写入提示词、对话正文、命令参数、工具参数、stdout/stderr、凭据、令牌、堆栈或隐藏推理。关闭后不再产生普通运行事件。
- 开发工作区可用 `pnpm run probe:runtime-diagnostics -- --tail=100` 读取最近记录，并以 `--session`、`--operation`、`--trace`、`--provider`、`--task-ref`、`--scope`、`--event`、`--level` 或 `--since` 缩小范围；输出同时聚合状态变化、no-op、快捷键、跳转、归档阶段和错误码。探针只读，不修改日志和任务状态。

## 通用键盘与交互（全插件）

### 操作提醒

- 主窗口各功能页的按钮与操作控件共用一套提醒：鼠标短暂停留或键盘聚焦后，显示操作名称，并按需补充快捷键、说明或禁用原因。
- 同一控件只显示一个提醒；提醒不会遮挡点击，按下操作、按 `Escape`、窗口失去焦点或控件离开页面后会收起。
- 打开快速跳转标记层时，主窗口操作提醒暂停，避免与目标标记竞争。
- Codex 独立悬浮子窗不挂载主窗口提醒层，继续使用子窗自己的操作提示。

### 功能切换与隐藏

- `Ctrl+Shift+1…n`：按**当前启用功能顺序**切换 Tab（随功能开关排序变化）
- `Ctrl+Alt+S`：打开设置
- `Shift+Escape`：立即隐藏插件窗口

### 左右抽屉（多数列表页）

- `Ctrl/⌘+←`：打开或切到**详情**
- `Ctrl/⌘+→`：打开或切到**动作**
- 打开后面板获焦；左右切换会把焦点移到新面板；关闭后焦点回到触发行或稳定列表所有者
- 按钮、右键菜单与快捷键派发同一命令 ID
- 普通文本编辑框仍保留原生左右方向键；设置页仅在非编辑命令行上声明左右面板命令

### 快速跳转（Quick Jump）

- 非编辑焦点下默认 `F` 正向、`Shift+F` 反向打开目标标记层
- 标记落在目标矩形中心；点选只激活已有目标，不新建
- `Escape`：先清输入/进行中的标记查询，再关闭层，再交给更下层的抽屉/多选/搜索恢复
- Codex 悬浮子窗有自己的跳转变体与排除规则；打开跳转会关闭纯 Shift 预览

### Escape 恢复习惯

各页约定由内向外恢复：确认/编辑 → 预览/抽屉 → 多选 → 搜索/焦点 → 再考虑隐藏。具体顺序以当前页为准。

### 编辑 soul（多功能共用）

- `F2`：完整编辑；`Shift+F2`：重命名（或模块约定的轻量编辑）
- `Ctrl+S` / `Ctrl+Enter`：保存当前编辑层
- `Escape`：取消
- 编辑层内 `Tab` / `Shift+Tab`：字段循环，不切主 Tab

## 常用操作

1. 需要某功能时，到 **维护 → 功能开关** 启用并排序，保存。
2. 到 **快捷键** 按作用域查找命令，录制或编辑后保存草稿。
3. 若快捷键不符合预期，用 **解析候选** 对照当前上下文的命中结果。
4. MQTT 归档或本地库异常时，查看 **存储状态**。
5. 点击功能行 **说明** 阅读该功能的详细操作说明。
6. 安装后状态或归档异常时，保持默认 `debug` 复现一次，再打开当前文件/目录或运行只读探针；定位完成后可切到 `info/error`、关闭或确认清理旧日志。

## 风险与边界

- 快捷键未点保存前不会影响运行时。
- 解析候选与层级视图用于诊断，不会单独改写绑定。
- 功能关闭只隐藏能力入口，一般不自动清空该功能已有本地数据（以各功能自己的数据策略为准）。
- 关闭安装诊断日志不会自动删除现有 JSONL；容量和保留期仍由日志模块自动轮转。要清理时使用页面的 **清空日志** 并确认，该动作只删除模块自有日志文件。
