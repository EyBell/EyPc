# MQTT

通过 WebSocket 连接 MQTT Broker，管理连接与订阅，收发消息，并在本地归档记录、发送收藏与草稿历史。

**默认状态：** 启用。

## 入口

- 主窗口顶栏 **MQTT** Tab
- uTools 关键词：`MQTT`、`mqtt websocket`、`mqtt ws`、`消息调试`

## 主界面分区

- **连接树（左）：** 连接配置与**连接分组**（可折叠、拖拽整理、嵌套分组）
- **订阅栏：** 当前连接的订阅主题、别名与颜色
- **消息区：** 收发记录；筛选 `全 / 收 / 发 / 藏`；可用工具栏「切换布局」或 `Ctrl+Shift+S` 在上下与左右收发布局间切换（默认宽度即可切换，偏好会持久化）
- **发送区：** 发布主题、载荷、QoS/Retain；草稿历史弹层
- **详情 / 动作抽屉：** 对连接、分组、订阅、消息行等打开详情或操作菜单

## 连接与分组

1. 工具栏可 **新建连接**（默认 `Ctrl+N`）或 **新建分组**（默认 `Ctrl+G`）。
2. 新建目标受当前焦点影响：在连接行上操作时，可能继承该行所属分组；在空白栏或搜索等非行焦点处，通常创建到顶层。
3. 分组行可用 `←` / `→` 折叠/展开；支持拖拽把连接或子分组放进分组。
4. 连接配置包含：端点、Client ID、用户名、订阅列表、发布默认主题候选、重连与是否同步记录等。
5. **密码 / Token 只保存在本机加密密钥文件中**，不会进入可同步的应用状态、消息归档或模板。

连接后可用 `Ctrl+R`（默认）对当前连接执行连接/重连类操作（以动作抽屉与命令提示为准）。

## 订阅与筛选

- 按连接维护订阅主题；删除主题时会清理对应别名/颜色。
- 订阅栏：`Enter` 可把主题用作消息列表筛选；`Ctrl+C` 复制主题；`Ctrl+Enter` 填入发布主题。
- 顶部信息筛选：`Ctrl+1/2/3` 对应 `全/收/发`，`Ctrl+M` 对应 `藏`（发送收藏）。
- 主题下拉（默认 `Ctrl+Shift+F`）只列出当前连接订阅，用于过滤普通消息行。

## 发送、收藏与草稿

- 在发布编辑区填写主题与载荷后发送；可配置多个默认发布主题候选。
- `Ctrl+S`：在记录焦点下收藏/取消收藏当前记录；在发布编辑焦点下把当前主题/载荷存为模板。
- `Ctrl+H`：打开/关闭发送区草稿历史；`Ctrl+Shift+H`：手动保存当前草稿。
- 草稿历史行用「应用」按钮或 `Enter` 应用；`Ctrl+Enter` 可应用并发送且保持弹层打开。
- 纯 `Shift` 可对有效消息/模板/草稿行打开只读预览；`Ctrl/⌘+Shift` 组合留给快捷键，不打开预览。

## 关键快捷键

默认值可在 **设置 → 快捷键**（作用域「MQTT」）修改。

| 操作 | 默认 |
| --- | --- |
| 切换连接 / 订阅 / 消息 / 发布区 | `Tab` / `Shift+Tab` |
| 详情 / 动作 | `Ctrl+←` / `Ctrl+→` |
| 编辑订阅 | `F2` |
| 连接相关操作 | `Ctrl+R` |
| 新建连接 / 新建分组 | `Ctrl+N` / `Ctrl+G`（受连接栏焦点作用域影响） |
| 布局切换 | `Ctrl+Shift+S` |
| 主题下拉 | `Ctrl+Shift+F` |
| 进入发布主题框 | `Ctrl+P` |

连接栏多选：`Space`；复制地址：`Ctrl+C`。删除连接或分组：`Delete` / `Backspace`（在连接栏焦点下）。

## 风险与边界

- 密钥仅本地加密保存；不要把密码写进可导出的备注或公开配置分享。
- 消息与草稿归档优先本地 SQLite；旧版归档可回退兼容（见设置 → 维护 → 存储状态）。
- 删除连接/分组/订阅会去掉插件内配置与关联元数据，不会删除远端 Broker 上的数据。
- 本地弹层（主题、发布选项、草稿历史）叠在工作台之上，但仍低于全局抽屉与确认层。

## 与其它功能的关系

通用左右抽屉与快速跳转见 **设置** 说明。MQTT 专属快捷键与端口/收藏等作用域分开，冲突只在可同时生效的上下文中提示。
