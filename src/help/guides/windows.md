# 窗口跳转

收藏桌面窗口、维护稳定跳转槽位（1–10），并在需要时安全激活目标窗口。适合跨 Space / 多窗口时快速回到固定应用窗口。

**默认状态：** 关闭。启用后才会出现窗口 Tab；槽位全局功能仍由 uTools 功能列表提供，绑定在系统侧完成。

## 入口

- 主窗口 **窗口跳转** Tab
- uTools：`窗口跳转`、`窗口收藏`、`window jump`
- **EyPc 窗口槽 1–10**：`mainHide` 全局功能。成功跳转时直接激活目标，不先弹出插件主窗；失败时会打开工作台/设置侧并给出诊断说明

## 主界面

- **工具栏：** 搜索 + **手动加载** 活动窗口列表（不会在后台持续轮询桌面）
- **槽位条：** 1–10；点击未分配槽可进入选窗绑定；已分配槽可跳转；右键打开 uTools 快捷键设置；`Shift+点击` 清除槽位
- **状态 / 异常带：** 加载状态、阻塞性失败提示；会话内诊断有上限，不会写入长期应用配置
- **列表 / 操作 / 编辑层：** 列表置顶、收藏、分配槽位、别名编辑等

列表排序：列表置顶行优先，其余按应用名、显示名、标题、稳定 ID。收藏、列表置顶、槽位绑定互相独立——任一保留理由都可让目标在不可用时仍出现在列表中。

## 常用操作

1. 在功能开关中启用「窗口跳转」并打开该 Tab。
2. 点击手动加载，拉取当前可操作的桌面窗口。
3. 选中目标：可 **收藏**、**列表置顶**（只影响 EyPc 内排序），或分配到槽位 1–10。
4. 编辑别名（`F2` / `Shift+F2` 等以界面为准）：只改插件内显示名，**不会改真实窗口标题**。
5. 激活：在列表中执行展开/前置，或通过已绑定的全局槽位功能跳转。
6. 标题漂移时不会自动顶替：同进程不同标题只会成为「候选」，需你明确选中成功后才更新定位。

### 平台差异（按当前实现）

- **Windows：** 可对真实窗口做「页面置顶」（置顶第三方窗口）；可展示/复制校验过的 HWND。展开并前置会先恢复最小化再前置。
- **macOS：** 可展开并前置；**不会**伪造对任意第三方窗口的永久页面置顶。跨 Space跳转依赖权限与 Space 解析；失败时保持失败关闭，不随意挑一个窗口。缺辅助功能/自动化权限时会给出可引导到系统设置的状态。

## 关键快捷键

默认值可在设置（作用域「窗口跳转」）改绑。

| 操作 | 默认 |
| --- | --- |
| 列表上下移动 | `↑` / `↓` |
| 打开 / 关闭操作面板 | `→` 或 `Ctrl+→` / `←` 或 `Ctrl+←` |
| 列表与操作层切换 | `Tab` / `Shift+Tab` |
| 关闭窗口（先正常关闭） | `Ctrl+Delete` / `Ctrl+Backspace` |
| 保存 / 取消编辑 | `Ctrl+S` 或 `Enter` / `Escape` |
| 刷新列表 | `Ctrl+R`（以命令表为准） |

槽位的**系统级**快捷键在 uTools 功能绑定界面配置；EyPc 不会回读或展示宿主当前绑定内容，只提供跳转到官方绑定页的入口。

## 风险与边界

- 不会后台常驻扫描桌面窗口；全局槽位命中缓存失败时最多做一次有界补扫。
- 失败场景（找不到、歧义、无权限、Space 切换超时、精确焦点失败等）会阻塞并提示，而不是静默乱跳。
- 会话诊断不含窗口标题、应用名、PID、句柄等敏感原文（正式安装构建不暴露开发用原生逐步快照）。
- 别名变更不影响 uTools 功能条目本身。

## 与其它功能的关系

通用快速跳转 `F` 用于插件内控件定位，与窗口槽全局跳转不是同一套机制。功能启用与快捷键见 **设置**。
