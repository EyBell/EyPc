# 窗口跳转

收藏桌面主窗口、维护稳定跳转槽位（1–10），并在需要时安全激活整个目标窗口。适合在多应用、多主窗口之间快速切换；窗口内部的 Tab、编辑页或对话框变化不会产生额外目标。

**默认状态：** 关闭。启用后才会出现窗口 Tab；槽位全局功能仍由 uTools 功能列表提供，绑定在系统侧完成。

## 入口

- 主窗口 **窗口跳转** Tab
- uTools：`窗口跳转`、`窗口收藏`、`window jump`
- **EyPc 窗口槽 1–10**：`mainHide` 全局功能。成功跳转时直接激活目标，不先弹出插件主窗；失败时会打开工作台/设置侧并给出诊断说明

## 主界面

- **工具栏：** 搜索 + **手动加载** 活动窗口列表（不会在后台持续轮询桌面）
- **槽位条：** 1–10；点击未分配槽可进入选窗绑定；已分配槽可跳转；右键先打开统一槽位面板，可激活、重新选择、清除或进入 uTools 快捷键设置；`Shift+点击` 仍可快速清除
- **状态 / 异常带：** 加载状态、阻塞性失败提示；会话内诊断有上限，不会写入长期应用配置
- **主窗口树 / 操作 / 编辑层：** 普通应用按独立系统主窗口展示；Finder/Explorer 使用可展开父节点管理多个独立文件管理器窗口。列表置顶、收藏、分配槽位和别名编辑仍在原操作层完成

树排序：列表置顶节点优先，其余按应用名、显示名、标题、稳定 ID。收藏、列表置顶、槽位绑定互相独立——任一保留理由都可让目标在不可用时仍出现在树中。Finder/Explorer 即使只有一个窗口也保留父子结构，避免窗口数量变化时界面跳位。

## 常用操作

1. 在功能开关中启用「窗口跳转」并打开该 Tab。
2. 点击手动加载，拉取当前可操作的桌面窗口。
3. 选中目标：可 **收藏**、**列表置顶**（只影响 EyPc 内排序），或分配到槽位 1–10。文件管理器父节点表示“最近可用文件管理器窗口”，子节点表示一个精确文件管理器主窗口。
4. 编辑别名（`F2` / `Shift+F2` 等以界面为准）：只改插件内显示名。当前/上次窗口标题为只读信息，**不会改真实窗口标题**。
5. 激活：在列表中执行展开/前置，或通过已绑定的全局槽位功能跳转。
6. 浏览器 Tab、IDE 编辑页以及已被系统关系证明属于同一根窗口的 Sheet/Dialog/Tool Window 都不会改变主窗口身份；当前成员标题只帮助搜索和辨认。两个独立浏览器或 IDE 主窗口仍是两个目标，不会按应用合并。
7. Finder/Explorer 父节点按“当前焦点窗口 → 上次成功窗口 → 本会话最近窗口 → 当前树序第一窗口”激活。父节点没有实时子窗口时仍保留收藏/别名/槽位，但 EyPc 不会自动启动文件管理器。
8. 原主窗口真正失效后，EyPc 会保留原目标别名和上次标题，并列出同应用的**具体根窗口**候选；即使只有一个，也必须按 `Enter` 明确确认。完整/部分清单、候选状态和一次 `Escape` 恢复原目标焦点继续沿用，只有原生激活成功后才换绑。

### 平台差异（按当前实现）

- **Windows：** 用 `GA_ROOTOWNER` 把同应用 owned popup 等成员归到根 HWND。可前置当前/最后活动成员，但最终必须验证前台窗口仍属于目标根；可对具体根做「页面置顶」并复制校验后的 HWND。`PID+HWND` 只表示当前已核验定位，每次操作都会重新验证 owner、应用和可操作性。
- **macOS：** 用 PID + CGWindowID 与 AX 顶层/所属窗口关系证明成员到根，并以最终 `AXFocusedWindow` 所属根完成验证；无法证明时保持独立，不按标题、序号或“只有一个”猜测。可展开并前置，但**不会**伪造任意第三方窗口的永久页面置顶。当前实现不使用环境快照或 Space 查找/缓存/切换作为激活路径。

## 关键快捷键

默认值可在设置（作用域「窗口跳转」）改绑。

| 操作 | 默认 |
| --- | --- |
| 列表上下移动 | `↑` / `↓` |
| 展开父节点 / 进入首个子窗口 | `→` |
| 返回父节点 / 收起父节点 | `←` |
| 打开 / 关闭操作面板 | `Ctrl+→` / `Ctrl+←` 或 `Escape` |
| 列表与操作层切换 | `Tab` / `Shift+Tab` |
| 关闭窗口（先正常关闭） | `Ctrl+Delete` / `Ctrl+Backspace` |
| 保存 / 取消编辑 | `Ctrl+S` 或 `Enter` / `Escape` |
| 刷新列表 | `Ctrl+R`（以命令表为准） |

槽位的**系统级**快捷键在 uTools 功能绑定界面配置；EyPc 不会回读或展示宿主当前绑定内容，只提供跳转到官方绑定页的入口。

## 风险与边界

- 不会后台常驻扫描桌面窗口；全局槽位命中缓存失败时最多做一次有界补扫。
- 失败场景（根实例失效、成员关系不可证明、身份不可用、无权限、精确根焦点失败等）会阻塞并提示，而不是静默乱跳。
- 标题只用于展示、搜索和人工辨认，不参与自动匹配、实例验证或换绑。相同应用、相同标题但不同系统窗口实例永远不会自动判为同一窗口。
- 虚拟文件管理器父节点不参与批量选择，也不提供页面置顶、关闭全部或强制关闭全部；需要这些动作时展开并选择具体子窗口。
- 会话诊断不含窗口标题、应用名、PID、句柄等敏感原文（正式安装构建不暴露开发用原生逐步快照）。
- 别名变更不影响 uTools 功能条目本身。

## 与其它功能的关系

通用快速跳转 `F` 用于插件内控件定位，与窗口槽全局跳转不是同一套机制。功能启用与快捷键见 **设置**。
