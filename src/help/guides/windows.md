# 窗口跳转

收藏桌面主窗口、维护稳定跳转槽位（1–10），并跨显示器/桌面切回准确主窗口。浏览器 Tab、IDE 编辑页和标题变化不会改变绑定；可验证的真实原生子窗口只作为本次会话的精确落点。

**默认状态：** 关闭。启用后才会出现窗口 Tab；槽位全局功能仍由 uTools 功能列表提供，绑定在系统侧完成。

## 入口

- 主窗口 **窗口跳转** Tab
- uTools：`窗口跳转`、`窗口收藏`、`window jump`
- **EyPc 窗口槽 1–10**：`mainHide` 全局功能。成功跳转时直接激活目标，不先弹出插件主窗；失败时会打开工作台/设置侧并给出诊断说明

## 主界面

- **工具栏：** 搜索 + **手动加载** 当前可观察窗口（不会后台轮询；其他 macOS Space 中已验证的目标会保留在会话缓存）
- **槽位条：** 1–10；点击未分配槽可进入选窗绑定；已分配槽可跳转；右键先打开统一槽位面板，可激活、重新选择、清除或进入 uTools 快捷键设置；`Shift+点击` 仍可快速清除
- **状态 / 异常带：** 加载状态与最新一次会话诊断提示（阻断失败会直接写在这里）；完整诊断列表在 **设置 → 维护 → 窗口诊断**，不在窗口列表侧栏常驻
- **主窗口树 / 操作 / 编辑层：** 普通应用显示“真实主窗口 → 真实子窗口”；同应用的多个独立主窗口保持并列。Finder/Explorer 是唯一例外，只显示“虚拟文件管理器父节点 → 真实主窗口”，不会出现第三级。收藏、列表置顶、槽位和别名只属于真实主窗口或文件管理器虚拟父节点

树排序：已绑定稳定槽的节点按槽号从小到大优先；其后是列表置顶节点；其余按应用名、显示名、标题、稳定 ID。收藏、列表置顶、槽位绑定互相独立——任一保留理由都可让目标在不可用时仍出现在树中。Finder/Explorer 即使只有一个窗口也保留父子结构，避免窗口数量变化时界面跳位。

## 常用操作

1. 在功能开关中启用「窗口跳转」并打开该 Tab。
2. 点击手动加载，拉取当前可操作的窗口投影。macOS 当前投影看不到其他 Space 时，不代表那些窗口已经关闭。
3. 选中真实主窗口：可 **收藏**、**列表置顶**（只影响 EyPc 内排序），或分配到槽位 1–10。普通应用主窗口下的子节点是本会话的精确落点，不会被收藏或绑定槽位；文件管理器父节点表示“最近可用文件管理器主窗口”。
4. 编辑别名（`F2` / `Shift+F2` 等以界面为准）：只改插件内显示名。当前/上次窗口标题为只读信息，**不会改真实窗口标题**。
5. 激活主窗口：双击/`Enter` 主窗口或使用槽位。EyPc 会按唯一原生实例定位，必要时只切换目标显示器到目标 Space，再验证最终焦点。因此另一显示器切换桌面、目标显示器暂时停在别的桌面、浏览器从 Tab1 切到 Tab2，都不应破坏原收藏和槽位。
6. 激活指定子窗口：展开普通应用主窗口，双击/`Enter` 一个子节点。EyPc 会重新验证它仍属于该主窗口并精确聚焦；如果它已经消失或关系改变，会明确失败，不会打开主窗口或兄弟子窗。
7. 子窗口只提供精确打开、能力允许时精确关闭、只读详情，以及 Windows HWND 复制；不支持收藏、列表置顶、改名、槽位、多选、页面置顶、强制关闭或批量动作。两个独立浏览器或 IDE 主窗口始终是两个一级目标，不会按应用合并。
8. Finder/Explorer 父节点按“当前焦点窗口 → 上次成功窗口 → 本会话最近窗口 → 当前树序第一窗口”激活。父节点没有实时主窗口时仍保留收藏/别名/槽位，但 EyPc 不会自动启动文件管理器。
9. 当前清单缺席会显示“当前桌面未观察到”或“当前无法确认”，并保留目标和槽位。只有原生定点探测确认窗口真正不存在，才清除原生引用并列出同应用的**具体主窗口**候选；即使只有一个，也必须按 `Enter` 确认。由某个槽位发起的恢复只修改该槽位。

### 平台差异（按当前实现）

- **Windows：** 只读取用户可见、可激活的顶层/owned popup，使用 `GA_ROOTOWNER` 证明同应用主子关系；控件 HWND、cloaked、no-activate、透明隐藏、宿主和系统辅助表面会被过滤。主窗口激活验证最终前台仍属于该根；指定子窗还必须命中该 HWND。真实主窗口可用「页面置顶」，Windows 行可复制校验后的 HWND。
- **macOS：** 从普通应用的可操作 AX 窗口出发，用正 CGWindowID 佐证身份，并用 AX parent/top-level/window 关系证明主子结构。主窗口/指定子窗最终都由 `AXFocusedWindow` 精确回读。会话内按 CGWindowID 缓存显示器/Space，使用直接与反向 SkyLight 查询，只切换目标显示器；缓存不会持久化，也不会后台扫描。不会按标题、应用名、序号、位置、大小或“只有一个”猜测。

## 关键快捷键

默认值可在设置（作用域「窗口跳转」）改绑。

| 操作 | 默认 |
| --- | --- |
| 列表上下移动 | `↑` / `↓` |
| 展开主/父节点，或进入首个子窗口 | `→` |
| 返回主/父节点，或收起节点 | `←` |
| 打开 / 关闭操作面板 | `Ctrl+→` / `Ctrl+←` 或 `Escape` |
| 列表与操作层切换 | `Tab` / `Shift+Tab` |
| 关闭窗口（先正常关闭） | `Ctrl+Delete` / `Ctrl+Backspace` |
| 保存 / 取消编辑 | `Ctrl+S` 或 `Enter` / `Escape` |
| 刷新列表 | `Ctrl+R`（以命令表为准） |

槽位的**系统级**快捷键在 uTools 功能绑定界面配置；EyPc 不会回读或展示宿主当前绑定内容，只提供跳转到官方绑定页的入口。

## 风险与边界

- 不会后台常驻扫描桌面窗口；热槽位只刷新显示器当前 Space，缓存失效时只定点解析该目标并最多重试一次。
- 失败场景（主窗口已确认失效、子窗口失效、Space 绑定不唯一、关系不可证明、身份不可用、无权限、精确焦点失败等）会阻塞并提示；“未观察到”不会被显示成“已关闭”，指定子窗失败绝不回退到主窗口或兄弟窗口。
- 标题只用于展示、搜索和人工辨认，不参与自动匹配、实例验证或换绑。相同应用、相同标题但不同系统窗口实例永远不会自动判为同一窗口。
- 无法证明是用户可见、可操作窗口的原生句柄/表面会被完全省略，不建立应用级回退分组。
- 子窗口和虚拟文件管理器父节点不参与批量选择；文件管理器虚拟父节点也不提供页面置顶、关闭全部或强制关闭全部。
- 会话诊断不含窗口标题、应用名、PID、句柄等敏感原文（正式安装构建不暴露开发用原生逐步快照）。正式安装后完整诊断只在 **设置 → 维护 → 窗口诊断** 查看；窗口列表页仅用状态带提示最新一条。
- 别名变更不影响 uTools 功能条目本身。

## 与其它功能的关系

通用快速跳转 `F` 用于插件内控件定位，与窗口槽全局跳转不是同一套机制。功能启用与快捷键见 **设置**。
