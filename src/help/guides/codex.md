# Codex

额度悬浮球与任务收件箱：在独立 Tab 配置外观与快捷方式，用桌面悬浮窗查看额度与近期任务状态，并支持只读打开 Codex 会话相关动作。

**默认状态：** 启用。首次启用后会做隐私最小化的环境检测（即使当时未打开 Codex Tab）。

## 入口

- 主窗口 **Codex** Tab
- uTools：`eypc-codex` 及相关全局功能（显示/隐藏悬浮球、直接展开卡片、待输入、已完成未读、上一个/下一个任务等）
- 插件内默认：`Ctrl+Alt+Q`（macOS 常为 `Command+Option+Q`）切换悬浮球；`Ctrl+Alt+Enter` 显示并展开卡片
- **Environment Action 槽 1–5**：可在 Codex「快捷方式」里点「去设置」，到 uTools 全局功能绑定系统级快捷键（功能名：`Codex Action 槽 N`）

## 配置页分区

顶部导航（同一时间只渲染当前分区）：

1. **快捷方式** — 打开 uTools 绑定页或执行入口；**不读取、不回显**宿主当前快捷键绑定
2. **任务** — 任务列表展示相关选项（滚动窗口天数等）
3. **水球** — 紧凑悬浮球外观与读数
4. **卡片** — 展开面板主题（与水球配色独立）
5. **运行** — 环境诊断、连接状态、刷新策略等

说明性细节多用可聚焦的「i」提示，避免整页永久展开大段说明。

## 悬浮球与展开卡片

- 紧凑水球：显示额度读数与角标计数（待输入 / 进行中相关 / 已完成未读等；为 0 的角标会隐藏，超过 99 显示 `99+`）
- 上半可点计数区、下半拖动区等分区以当前界面为准；展开后进入任务卡片
- 展开卡片内任务 Tab：**动态 / 已完成 / 已隐藏 / 项目**
- 额度后直接进入来源状态与任务内容；展开卡**不显示** Actions/Environment 卡槽、选择层或 Setup 提示
- 点击其它位置、指针/焦点离开时约 220ms 自动收回水球；编辑器、详情/抽屉、Quick Jump、预览或调整尺寸期间会暂缓
- 外观：内置多套主题；水球与展开卡片可分别配置；对比度不合法的配色会被限制

## Environment Action

- **目标：** Controller 先使用 Codex 配置里的 **Action 默认项目**，未配置时回退到当前置顶/最近项目候选；Float 不另存项目或 Environment 选择状态
- **全局快捷键：** Codex「快捷方式」中为 1–5 分别「去设置」，绑定 uTools 全局功能 `Codex Action 槽 N`；卡内 `Ctrl+Shift+1…5` 也只派发同一 Controller 命令，Git Push 需 5 秒内再次触发确认
- **多 Environment：** Controller 使用本会话记住的 Environment，否则默认第一个；展开 Float 不提供 picker
- **Setup：** 不进入可执行命令，不会执行
- **Serve：** 由 Host 管理长驻会话；再次触发对应命令可停止
- **Git Push：** 外部写入，需 5 秒内再次确认
- 界面不展示路径、命令原文或 PID
- 默认项目在主窗口 Codex → **任务** 中配置；选「不配置」时使用置顶/最近项目回退

## 任务行为（用户可见）

- **动态：** 展示近期（按最新 Turn 活动，默认关注约六小时内非隐藏进行中类任务）与待输入等状态分段；置顶任务排在分段内靠前
- **待输入：** 含需你确认的 Plan 等；角标可直达第一条
- **已完成未读：** 打开第一条任务；是否未读只跟随 Codex Desktop 的原生 read-state，EyPc 打开、隐藏或恢复都不充当未读权威
- **已停止：** 单独中性状态，不计入进行中角标，也不能归档
- **状态时机：** 全新任务仍会先安全登记项目与匿名身份；若事件到达时完整列表暂时还没出现它，Preload 会按该脏任务精确读取一次，并且只有项目、最新 Turn 与匿名动作门禁全部通过才同时加入卡片和角标，不会先做一个假数字。首次读取未命中时，仍为 live active 的未登记状态会留在 Preload 等真实列表追上；任务偶尔从完整清单暂缺时，既有匿名活动映射会在同一数据源下短暂保留，避免隔离复查期间把仍在运行的任务误判为停止。已在任务池中的任务收到完整新 Turn 时，进行中卡片与角标会直接同步；完整且新鲜的完成 Turn 按同一 Turn 的状态版本直接切换，不会因服务端秒级完成时间与本机毫秒观测时间无法严格比较而丢失。曾被中断的同一 Turn 恢复时即使沿用原开始时间、又漏掉中间进行中事件，最新明确 completed 仍会前进到已完成。Desktop 首次订阅若重放一个与最新 terminal Turn 冲突的 active，EyPc 会在短暂定向核验期间先保守显示进行中，只有状态 revision 未变化、没有更新的明确进行中证据且最终读取仍 terminal 才一次切换；失败/中断冲突只会降为无法确认，不会合成“空闲/已停止”。任何真实新 Turn、等待请求、活动更新或读取失败都会保留/恢复进行中；即使活动本身未变化，新出现的 Plan/权限等待也会立即进入待输入并覆盖旧完成证据。反向也一样：新到达的 App Server 进行中证据不会再被旧的 Desktop idle 活动记录、未读变化、重新订阅或完整扫描回放成“已停止”；只有真正后到的停止活动或明确 terminal 证据才能结束它
- **切换任务：** 在 Codex Desktop 中切换任务只会改变 Desktop 当前关注对象；EyPc 会继续续订仍在任务池中的上一任务，不会让已停止任务重新进入进行中角标。若切换恰好与上一任务完成同时发生，即使 Desktop 短暂回放旧 active，EyPc 也会对该任务做一次有界的最新 Turn 校对，用明确 completed 同步完成分段与角标；校对期间若收到更新的进行中证据，旧校对结果会失效。Side Chat 会校对实际子任务并把活动、待输入与未读聚合回父任务。仍在运行或读取失败时继续保守显示进行中。完全退出 Codex、归档或任务确实离库时，仍按对应权威边界清理
- **多分支与诊断：** 一个 Side Chat 结束时，如果主任务或另一个 Side Chat 仍在运行，父任务继续显示进行中，不会被单个分支的晚到终态改成已停止/已完成。「运行」中的“状态裁决”常驻只显示保护合计与周期数，聚焦或悬停信息按钮可查看五项匿名明细；只有计数确实变化时刷新，普通轮询不会重复播报，也不含任务 ID、名称、正文或路径
- **版本提示：** uTools 若仍保留旧版任务桥，EyPc 会保留当前可用的任务卡片与三个角标，在状态摘要中标记“状态已保留，建议重载”；额度仍可继续显示。任务卡片、分组、角标、ARIA、设置预览和前后任务 active 候选来自同一个 Controller 状态包，不会因版本不一致被不同界面分别清空。若旧 Controller 已经发布了空数据，正常重载后会重新读取
- **归档：** 仅在已完成证据明确时可用；项目级「归档已完成」会按批处理并保留个别失败结果
- **上一个 / 下一个 Codex 任务：** 在「完整待输入集合 → 近六小时非隐藏进行中」池中循环；池空时回退到当前未停止的 EyPc 本地置顶任务。两者**只打开**，不标记未读、不改隐藏/Tab、不写 Desktop 状态

列表不展示任务正文；预览与详情也只含隐私安全字段（名称、项目、状态与时间等），不含路径、原始 ID、正文。

## 数据与平台边界

- **额度、模型、任务清单：** 来自本机 Codex App Server 连接（只读库存为主）
- **实时待输入 / 进行中 / 完成未读细分：** 依赖 macOS 上 Codex Desktop 实时桥；桌面未运行或桥不可用时，不会用本地缓存伪造 Input/进行中，未确认项会保守显示为进行中类
- **Windows：** 支持 CLI 发现与校验；Desktop 实时桥仍以 macOS 能力为准，Windows 上实时细分可能不可用
- 普通库存扫描对 Codex 全局状态文件保持只读；唯一写例外是你明确确认的原生项目移除事务
- Easy Agent 尚未实现；当前为 App Server +（macOS）Desktop 桥的过渡方案

## 常用配置步骤

1. 确认功能已启用；打开 Codex Tab 查看「运行」诊断。
2. 在「快捷方式」为常用全局动作到 uTools 里绑定系统快捷键。
3. 在「水球 / 卡片」调整外观，预览与桌面悬浮共用同一套渲染逻辑。
4. 显示悬浮球后，用角标或展开卡片处理待输入与未读；需要时用上一个/下一个任务循环。
5. 如需项目 Action，在「任务」配置默认项目或置顶常用项目，再通过五个全局功能/快捷键执行（以该项目 TOML 为准）；展开 Float 不显示 Action 卡槽。

“进行中离开稳定窗”已取消：普通快照、完整完成通知、缓存结果和 active 退出后的定向核验，只要通过同一 Turn revision/status 门禁都会立即同步。旧的 0.5–3 秒保存值已不进入当前运行设置，下次正常保存时会自然淘汰。已接受的完成同时关闭本次活动周期，后续相同快照不会将它反判回进行中。首次 active snapshot 冲突核验、完整清单校对和任务缺行保护仍保留。

插件内 Codex Tab 另有 `Ctrl+T`（默认）在当前高亮会话或项目中新建会话（受 Tab/输入层约束）。

## 风险与边界

- 不向界面、日志、可同步存储暴露原始会话 ID、路径、Token、正文。
- 破坏性操作（如归档、项目移除、Git Push）需要确认；失败不会乐观删行。
- Action 是 EyPc 等价执行，不会调用不存在的 Codex 原生 Action API。
- 动作后隐藏插件时，不会为了切 Tab 而清掉正在进行的循环所需状态（实现已避免错误切 Tab 导致别名失效）。

## 与其它功能的关系

功能总开关在 **设置 → 功能开关**。通用快速跳转在 Codex 子窗有本地变体；主插件 `F` 跳转习惯见 **设置** 说明。
